# Supplementary Material

## Multiobjective Ant Colony Optimization: An Updated Review from Designs to Applications

This repository contains the supplementary material accompanying the chapter:

**Multiobjective Ant Colony Optimization: An Updated Review from Designs to Applications**

### Authors

- Jesús Guillermo Falcón-Cardona
- Arturo Benjamin Hurtado-Perez
- Guillermo Leguizamón
- Ginna N. Enriquez
- Carlos A. Coello Coello

## Contents

The supplementary material provides the extended information supporting the classifications and analyses presented in the main chapter.

It includes:

- **Table SM-1 — Controlled terminology:** definitions of the compact terminology used for the MOACO taxonomical axes and auxiliary descriptors.
- **Table SM-2 — Benchmark problems:** extended paper-level classification of the benchmark studies under the component-oriented MOACO taxonomy.
- **Table SM-3 — Real-world problems:** extended classification of the application studies, retaining one row per application study.

These tables preserve detailed terminology and paper-level information that is intentionally compressed in the main chapter.
